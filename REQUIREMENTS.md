# Требования: игра «Пятнашки»

## Технологии
- Python + PySide6; приложение для личного использования.

## Функции
- Настройка размера игрового поля.
- Четыре режима: числа, изображение, Machine Art и Waifu.im.
- Выбор изображения из Openverse и Waifu.im, разбиение его на фрагменты по клеткам.
- Waifu.im — четвертый режим с переключателем SFW/NSFW; переключение заново запрашивает список.
- Machine Art — третий режим в селекторе, при выборе автоматически открывается окно генерации.
- Доступны алгоритмы «Цветовые поля», «Градиентные волны», «Геометрическая мозаика» и «Клеточный узор».
- Окно показывает превью и имеет кнопку перегенерации. Никаких проверок сходства или лимитов нет.
- Выбор алгоритма автоматически запускает генерацию. Повторный вход в режим Machine Art также запускает генерацию.
- Применение сохраняет изображение для режима Machine Art; отмена возвращает предыдущий режим и не изменяет текущую картинку.
- Перемещение соседней с пустой клеткой пятнашки кликом.
- Быстрое перемещение: зажать пустую клетку и вести курсор через соседние клетки; каждая пройденная пятнашка автоматически сдвигается в пустоту. Во время жеста разрешено менять направление.
- Показывать завершение игры после сборки поля.

## Интерфейс
- Окно игры с полем, настройкой размера, переключателем режимов «Числа / Изображение / Machine Art / Waifu.im», выбором изображения и перемешиванием.
- Диалог Waifu.im с переключателем SFW/NSFW и обновлением списка после смены фильтра.
- Понятно отображать пустую клетку.
- Диалог Machine Art с селектором алгоритма, превью, кнопками перегенерации, применить и отмена.
